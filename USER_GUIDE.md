# Руководство пользователя SQL2Py

**Версия 1.0.0.** SQL2Py переводит один запрос SELECT из файла .sql в
самостоятельный скрипт Python. При запуске этот скрипт читает локальную таблицу
CSV или JSON и выдаёт результат в формате JSON.

## Запуск на Windows

Готовый комплект рассчитан на Windows 10 или 11 x64. Для установки поместите
папку Kyrsach_tr в выбранный каталог. Сохраните sql2py.exe, sql2py.pyz
и runtime вместе в папке bin. В комплекте уже есть CPython 3.12.
Откройте PowerShell в папке Kyrsach_tr, где находятся bin и examples.

~~~powershell
.\bin\sql2py.exe --version
.\bin\sql2py.exe --help
.\bin\sql2py.exe examples/summary.sql -o summary.py
.\bin\runtime\python.exe summary.py examples/orders.csv
.\bin\runtime\python.exe summary.py examples/orders.json -o summary_json.json
~~~

Третья команда создаёт summary.py. Четвёртая показывает ответ в консоли,
пятая сохраняет ответ в summary_json.json. Для демонстрационного запроса итог
составляет 250 в Москве, 125 в Казани и 90 в Перми.

При использовании исходников нужен установленный Python 3.10 или новее.
Команды из каталога проекта выглядят так.

~~~powershell
python -m sql2py examples/summary.sql -o summary.py
python summary.py examples/orders.csv
~~~

## Свой запрос и свои данные

SQL-файл сохраните в UTF-8. В одном файле допустим один запрос SELECT к одной
таблице. Набор предложений идёт в следующем порядке.

~~~sql
SELECT city, COUNT(*) AS orders, SUM(amount) AS total
FROM orders
WHERE status = 'paid'
GROUP BY city
ORDER BY total DESC, city ASC
LIMIT 3;
~~~

Выборка поддерживает SELECT *, список столбцов и псевдонимы AS. В WHERE
разрешены сравнения, AND, OR, NOT, круглые скобки, IS NULL и IS NOT NULL.
Агрегаты — COUNT, SUM, AVG, MIN и MAX. Для GROUP BY указываются столбцы,
а для ORDER BY — поля результата. При SELECT * доступны поля исходной таблицы.
LIMIT задаётся целым числом без знака. Заключительная точка с запятой
необязательна.

В обычных именах используются латинские буквы, подчёркивание и цифры после
первого символа. Имена с пробелами и кириллицей заключаются в двойные кавычки.
В строковых значениях используются одинарные кавычки, а апостроф удваивается,
например 'О''Брайен'. Имена столбцов и ключевые слова сопоставляются без учёта
регистра. Значения строк сравниваются с учётом регистра.

Имя из FROM по умолчанию сопоставляется с именем файла данных без расширения.
Чтобы использовать другой файл с такими же полями, укажите логическое имя
параметром --table. Для CSV с точкой с запятой можно указать --delimiter ";",
для табуляции — --delimiter tab. Путь с пробелами заключите в кавычки.

~~~powershell
.\bin\runtime\python.exe summary.py "данные/заказы ноябрь.csv" --table orders --delimiter ";"
~~~

- **CSV** содержит заголовки в первой непустой записи и одинаковое число полей
  в каждой последующей записи. Разделитель по умолчанию — запятая. Пустое поле
  становится NULL. Заголовки обязательны. Допустимы также точка с запятой и
  табуляция, а кодировка входа ограничена UTF-8 с необязательным BOM.
  Правила записи полей в кавычках описаны в [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180.html).
- **JSON** содержит массив плоских объектов. Допустимы строки, числа, логические
  значения и null. Отсутствующее свойство рассматривается как NULL. Формат
  описан в [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259.html).
- **SQL** реализован как подмножество SELECT. За рамками реализации остаются
  соединения, подзапросы, HAVING, арифметические выражения, изменение данных
  и выполнение нескольких операторов из одного файла. Сортировка использует
  поля результата, значения NULL ставятся последними. Обычные столбцы в
  агрегатной выборке должны входить в GROUP BY.
  [SQL/Foundation ISO/IEC 9075-2:2023](https://www.iso.org/standard/76584.html).
  [Синтаксис LIMIT в PostgreSQL](https://www.postgresql.org/docs/18/sql-select.html).

Полное описание типов и ограничений дано в [LANGUAGE.md](LANGUAGE.md),
грамматика — в [grammar/sql.g](grammar/sql.g).

## Диагностика

При запуске транслятора без аргументов или с неверными аргументами появляется
краткая справка. Ошибка SQL содержит имя файла, строку и позицию. Например,
запрос из examples/invalid.sql использует city вместе с SUM(amount) и требует
GROUP BY city. Запрос из examples/missing_column.sql успешно переводится,
затем при обработке примера данных программа сообщает об отсутствии discount.

| Код завершения | Транслятор | Сгенерированный скрипт |
| --- | --- | --- |
| 0 | Трансляция, версия или справка | Успешное выполнение или справка |
| 1 | Ошибка SQL | Ошибка формата данных, вычисления или сохранения |
| 2 | Ошибка параметров запуска | Ошибка параметров запуска |
| 3 | Ошибка открытия или записи файла, превышение размера SQL-файла или ошибка запуска встроенного Python | — |

Демонстрационные файлы находятся в examples. Команды, фактические выводы
и коды завершения записаны в [verification/demo](verification/demo/commands.txt).
